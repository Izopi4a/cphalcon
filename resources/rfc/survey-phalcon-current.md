# Survey: Phalcon 7.0.x — current Forms, Validation, Events, Html, Container (what exists to build on)
(Read-only survey by a research agent, 2026-10-15, Zephir sources under phalcon/ on branch T17106-forms-overhaul.)

**Short version:** nothing supports nested fields or dotted paths; `Form` fires no EventsManager events (only `method_exists` hooks); element values reach helpers typed as `string`; TagFactory helpers are cached stateful singletons.

## 1. phalcon/Forms
`Form extends Phalcon\Di\Injectable implements Countable, Iterator, AttributesInterface`. Props: `attributes` (Html\Attributes), `data`, `filteredData`, `elements` (by name), `elementsIndexed`, `entity`, `messages`, `position`, `options`, `tagFactory`, `validation`, `whitelist`.
Public API: `__construct(entity = null, array userOptions = [])` (throws if entity not object; calls `initialize(entity, userOptions)` if defined); `add(ElementInterface, position = null, bool type = null)` (calls `setForm(this)`, pushes tagFactory; type=true inserts before position else after); `bind(array data, entity = null, array whitelist = [])`; `clear(fields = null)`; `count/current/key/next/rewind/valid` (positional `elementsIndexed`, rebuilt by `rewind()` with array_values); `get(name)` (throws), `has`, `remove`; `getElements`, `getEntity/setEntity`; `getAction/setAction` (= `action` attribute); `getAttributes/setAttributes`; `getValue(name)`, `getFilteredValue(name)`; `getLabel(name)` (falls back to name); `label(name, attrs)`, `render(name, attrs)` (delegate to element); `getMessages()` (empty Messages if none), `getMessagesFor`, `hasMessagesFor`; `getTagFactory/setTagFactory`, `getValidation/setValidation(ValidationInterface)`, `getWhitelist/setWhitelist`; `getUserOption(o, default)`, `getUserOptions`, `setUserOption`, `setUserOptions`; `isValid(data = null, entity = null, whitelist = [])`.
Binding: `bind()` loops data, skips non-elements / not whitelisted; filters via `filter->sanitize()` (`getDI()->getShared("filter")`); writes entity: `set<Camelize(key)>()` if exists, else `entity->{key} = v` when ini `form.strict_entity_property_check` off (via `Phalcon\Support\Settings::get`), else only if `property_exists`. Raw values -> `data`, filtered -> `filteredData`.
`getValue(name)` order: `getCustomValue(name, entity, data)` if exists; entity `get<Camelize>()`; entity public prop; `data[name]`; `$_POST[name]`; forbidden internal names -> null; `this->get<Camelize>()` on form; `element->getDefault()`. `getFilteredValue` = filteredData then getValue.
`isValid`: bind; hook `beforeValidation(data, entity)` (false aborts); `getValidation()` or new `Phalcon\Filter\Validation`; per element `validation->add(name, validator)` + `setFilters(name, filters)`; `validation->validate(data, entity)`; per message `this->get(msg->getField())->appendMessage(msg)`; `this->messages` set only on failure; hook `afterValidation(messages)`.
Pitfalls: validators appended to a user-supplied validation on every call (repeated isValid duplicates); element messages never cleared; messages for combined fields ("a, b") or non-element fields make `get()` throw; `remove()` resets `elementsIndexed` only when element NOT found (inverted); forbidden key "tagFactory" never matched (lowercased first).
Events: none via EventsManager; hooks `beforeValidation`/`afterValidation`/`initialize`/`getCustomValue` by `method_exists`. `tests/unit/Forms/Form/SetEventsManagerTest.php` skipped ("Need implementation").
`Manager`: `create(name, entity = null)`, `get`, `has`, `set(name, Form)`.
`ElementInterface`: `addFilter`, `addValidator`, `addValidators(array, merge = true)`, `appendMessage`, `clear`, `getAttribute(s)`, `getDefault`, `getFilters`, `getForm`, `getLabel`, `getMessages`, `getName`, `getUserOption(s)`, `getValidators`, `getValue`, `hasMessages`, `label()`, `render(array)`, `setAttribute(s)`, `setDefault`, `setFilters`, `setForm`, `setLabel`, `setMessages`, `setName`, `setUserOption(s)`.
`AbstractElement`: `__toString`, `getTagFactory/setTagFactory`, protected `getLocalTagFactory()` (element, then form, then `Di::getDefault()->getShared("tag")`, else `Exception::tagFactoryNotFound()`). `getValue()` delegates to `form->getValue(name)` (no form: default). `render(attrs)` = `tagFactory->newInstance(this->method)->__invoke(name, value, array_merge(attributes, attrs))`; `attrs["value"]` overrides. `label(attrs)` = `tagFactory->label(labelName, attrs)`, `for` = id attr or name.
Elements -> helper `method`: Text inputText, Check inputCheckbox, Date inputDate, Email inputEmail, File inputFile, Hidden inputHidden, Numeric inputNumeric, Password inputPassword, Radio inputRadio, Submit inputSubmit, TextArea inputTextarea. `Select` is special: `__construct(name, options = null, attrs)`, `addOption/getOptions/setOptions`; `render()` -> `prepareAttributes()`, handles `useEmpty`/`emptyValue`/`emptyText`/`using`, `newInstance("inputSelect")->__invoke("", "", attrs)->selected((string) value)->addPlaceholder()->fromData(new ArrayData(...) | new ResultsetData(rs, using))`, fallback `newInstance("element")`.
Nesting/array names: none. Only `Select` checks `!strpos(name, "[")` to skip id. `AbstractInput` sets `id = name` (invalid ids for `a[b]`). bind/getValue flat keys only. No tests with array-named fields.

## 2. phalcon/Filter/Validation
`Validation extends Injectable implements ValidationInterface`: `__construct(array validators)` (calls `initialize()` if defined); `add(field|array, ValidatorInterface)` (array + `AbstractCombinedFieldsValidator` -> `combinedFieldsValidators`), `rule()` alias, `rules(field, array)`; `appendMessage`, `bind(entity, data, whitelist)`, `getData`, `getEntity/setEntity`, `getFilters(field)/setFilters(field|array, filters)`, `getLabel(field)/setLabels(array)`, `getMessages`, `getValidators/setValidators`, `getValueByEntity`, `getValueByData`, `getValue`, `validate(data, entity, whitelist)` (Messages or false), `fails()`.
`validate`: resets values/messages; entity given -> `bind()` (sanitize, write via `set<Camelize>()`, then `writeAttribute()`, then property if exists); hook `beforeValidation(data, entity, messages)`; per field per validator: `preChecking()` handles `allowEmpty`, `validator->validate(this, field)`, `cancelOnFail` stops that field; combined validators; hook `afterValidation(data, entity, messages)`.
`getValue(field)`: entity -> `getValueByEntity` (`get<Camelize>()`, `readAttribute()`, `isset entity->{field}`) fallback `getValueByData` (cached `values`, `data[field]` or `data->{field}`); filters applied; filtered value written back to entity. NO nested path support anywhere.
`AbstractValidator`: `__construct(options)` (`template`/`message`/`[0]` -> template, per-field if array); `getOption/hasOption/setOption`, `getTemplate(field)/getTemplates`, `setTemplate(s)`; `messageFactory(validation, field, replacements)` -> `new Message(strtr(template, [":field" => label] + repl), field, get_class(this), code)`; protected `allowEmpty`, `checkArray`, `prepareCode`, `prepareLabel`.
`ValidatorInterface`: `getOption`, `getTemplate(s)`, `hasOption`, `setTemplate(s)`, `validate(Validation, field): bool`. `ValidatorCompositeInterface`: `getValidators()`, `validate()`. `AbstractValidatorComposite`, `AbstractCombinedFieldsValidator`, `ValidatorFactory` (camelCase names e.g. `presenceOf`), `Validation\Exception`, `Validator\Exception`.
Validators: Alnum, Alpha, Digit, Between (minimum/maximum), Callback, Confirmation (`with`, `ignoreCase`), CreditCard, Date (`format`), Email, ExclusionIn/InclusionIn (`domain`, `strict`), Identical (`accepted`/`value`), Ip, Numericality, PresenceOf, Regex (`pattern`), Url, StringLength (composite Min/Max), File (composite MimeType, Size\{Equal,Max,Min}, Resolution\{Equal,Max,Min} on File\AbstractFile), Uniqueness (combined-fields, DB backed).
Messages: `Phalcon\Messages\Message(message, field = "", type = "", code = 0, metaData = [])` + getters/setters + `jsonSerialize`; validators set `type` = class name, `field` = field or comma-joined, `metaData` empty. `Messages`: ArrayAccess/Countable/Iterator/JsonSerializable, `appendMessage(s)`, `filter(fieldName)`.

## 3. phalcon/Events
`Manager::fire("type:event", object source, data = null, bool cancelable = true)` (requires `:`); creates `new Event(eventName, source, data, cancelable)`; runs queue for `type` then for `type:event`. Handlers: closure/callable `(event, source, data)`; object handler needs method named after event; return = last handler's status. `Event::stop()` throws on non-cancelable; cancelable stops at first `isStopped()`. `attach(type, handler, priority = DEFAULT_PRIORITY 100)` in SplPriorityQueue; priorities ignored unless `enablePriorities(true)` (default false). Also `collectResponses()/getResponses()`, `detach`, `detachAll`, `getListeners`, `hasListeners`. Components implement `EventsAwareInterface` (`getEventsManager(): ?ManagerInterface`, `setEventsManager()`) or extend `AbstractEventsAware`, guard with `if eventsManager !== null { fire("form:beforeValidation", this, data) }`. `Form` extends Injectable but does not implement EventsAwareInterface.

## 4. phalcon/Html
`TagFactory extends Phalcon\Factory\AbstractFactory`: `__construct(EscaperInterface escaper, array services = [], ResponseInterface response = null)`; `__call(name, args)` = `newInstance(name)->__invoke(...args)`; `newInstance(name)` creates helper ONCE and caches in `services[name]` (`input*` get `(escaper, newInstance("doctype"))`, `preload` `(escaper, response)`, else `(escaper)`); `has(name)` checks `mapper`; `set(name, class)` overrides mapper, drops cached instance. Caching matters: helpers keep state (e.g. `Input\Select` `selected` never reset by `__invoke`).
Helpers: `a` (href, text, attrs, raw), `base`, `body`, `breadcrumbs` (add/render/setTemplate), `button` (text, attrs, raw), `close` (tag, raw), `doctype`, `element` (tag, text, attrs, raw), `form` (attrs; defaults method=post, enctype=multipart/form-data; open tag only), `friendlyTitle`, `img`, `label` (label, attrs, raw), `link`/`meta`/`script`/`style`/`title` (AbstractSeries), `ol`/`ul` (AbstractList: `__invoke(indent, delimiter, attrs)` then `add(text, attrs, raw)`), `preload`. `input*` from `Input\AbstractInput::__invoke(string name, string value = null, array attrs)` (sets type, name, `id = name`, drops empty non-numeric values): inputText, inputColor, inputDate, inputDateTime, inputDateTimeLocal, inputEmail, inputFile, inputHidden, inputImage, inputMonth, inputNumeric, inputPassword, inputRange, inputSearch, inputSubmit, inputTel, inputTime, inputUrl, inputWeek; `inputInput` (setType); `inputTextarea` (full element, value as content); `inputCheckbox` (`checked` when `attrs[checked] === value`, `unchecked` renders hidden input, `->label(attrs)` wraps); `inputRadio` extends Checkbox; `inputSelect` extends AbstractList (`add(text, value, attrs, raw)`, `addPlaceholder`, `optGroup`, `selected(string)`, `fromData(SelectDataInterface)`; `Select\ArrayData`, `Select\ResultsetData(resultset, using[2])`). Escaping via `escaper->html()`/`attributes()`; `true` attr -> bare attribute; `null` skipped.
`Escaper`: `attributes(array|string)`, `html`, `js`, `css`, `url`, `escape*` aliases, `setEncoding`, `setFlags`, `setDoubleEncode`, `setHtmlQuoteType`, `detectEncoding`, `normalizeEncoding`. `Html\Attributes extends Support\Collection implements RenderInterface` (`render()`, `__toString()`; orders rel,type,for,src,href,action,id,name,value,class; drops `escape`; throws on array values). `AttributesInterface`: `getAttributes/setAttributes`.

## 5. Container and Di
`Phalcon\Container\Container` (CapsulePHP-inspired): `set(name, definition)` (object|Closure|class string) -> `ServiceDefinition` (`setClass`, `setArgument`, `setFactory`, `setLifetime` SINGLETON|SCOPED|TRANSIENT, `addTag`, `addExtender`); `get(name)` shared/cached, `new(name)` fresh; `has`, `bind(interface, concrete)`, `setAlias(name, alias)` (cycle detection), `extend`, `setParameter/getParameter`, `getByTag`, `setInstance`, `unsetInstances(lifetime)`; autowiring on by default (`setAutowire()`), reflection resolvers. `ContainerFactory`: `addProvider(Provider)`, `newContainer()`; `Provider\Web` registers TagFactory as `tag`, FilterInterface as `filter`. `Di\InjectionAwareInterface` (`setDI`, `getDI`), `Di\AbstractInjectionAware extends stdClass`.

## 6. Support helpers
`Arr\Get(collection, index, default, cast)` flat keys; `Arr\Set(collection, value, index = null)` flat; `Arr\Has`, `Arr\Pluck`, `Arr\Whitelist`, `Arr\Blacklist`, `Arr\ToObject`, `Arr\Flatten`, `Arr\Group`, `Arr\Filter`, `Arr\First/Last`; `Str\Camelize(text, delimiters, lowerFirst)`, `Str\Uncamelize`, `Str\PascalCase`, `Str\SnakeCase`, `Str\KebabCase`, `Str\Humanize`, `Str\Underscore`, `Str\Interpolate`; via `Phalcon\Support\HelperFactory`. NO property-path / object accessor helper; Forms and Validation use Zephir builtin `camelize()` inline.

## 7. Volt function compilation
`Compiler::functionCall()` (~L1756) order for a plain identifier: extensions' `compileFunction`; user functions via `addFunction(name, string|Closure)` (L198; `addFilter` too); `get_content`/`content`, `partial`, `super`, `preload`; `Phalcon\Tag` if `method_exists("Phalcon\Tag", lcfirst(camelize(name)))` -> `\Phalcon\Tag::method(...)`; if DI has `tag` and `tag->has(name)` -> `$this->tag->name(args)`; `url`, `static_url`, `date`, `time`, `dump`, `version`... So a `Phalcon\Tag` method shadows a TagFactory helper of the same name; `addFunction` overrides both. `isTagFactory()` detects `tag.xxx()` member calls.
