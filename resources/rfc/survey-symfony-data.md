# Survey: Symfony Form — data mapping, transformers, PropertyAccess, listeners
(Read-only survey by a research agent, 2026-10-15. Recent Symfony: has ConstructorMapper, entry_name, allow_array_submission.)

## 1. Data flow (Form.php)
`setData` (L253-330): refuses if submitted / inherit_data / data locked. Object cloned if `by_reference` false. PRE_SET_DATA. No transformers -> scalar cast to string. `modelToNorm()` = each model transformer `transform()` in order; `normToView()` = each view transformer `transform()` in order (no view transformers: null/scalar -> (string)). View data checked against `data_class`. If children: `getDataMapper()->mapDataToForms($viewData, RecursiveIteratorIterator(InheritDataAwareIterator(children)))` (L321). POST_SET_DATA. `TransformationFailedException` here is NOT caught. `add()` also calls `mapDataToForms` for the new child once data set (L790).
`submit` (L423-615): false->null, scalar->string, file/array on non-compound -> immediate transformationFailure; PRE_SUBMIT; compound: each child `submit()` depth first, leftover keys -> `extraData`; view data = existing viewData (compound) or submitted value (simple); empty -> `empty_data` (Closure called with `$form, $viewData`); `mapFormsToData(iterator, $viewData)` (L571); `viewToNorm()` = view transformers `reverseTransform()` in REVERSE order (none: '' -> null); SUBMIT gets norm data; `normToModel()` = model transformers `reverseTransform()` reverse order; `normToView()` re-run; caught `TransformationFailedException` stored; POST_SUBMIT always runs.
Transformer order (FormConfigBuilder): `addViewTransformer()` appends (`$forcePrepend` -> first); `addModelTransformer()` PREPENDS (`$forceAppend` -> last), so the model transformer added last sits closest to the model. Every stage rethrows "Unable to transform/reverse ... for property path" keeping `getInvalidMessage()` + params.

## 2. DataMapper write-back rules (Extension/Core/DataMapper/DataMapper.php)
Default accessor `ChainAccessor([new CallbackAccessor(), new PropertyPathAccessor()])`.
`mapDataToForms`: null or `[]` = empty; non array/object -> `UnexpectedTypeException`. Child gets `getValue()` when data not empty, `getMapped()`, accessor `isReadable`; else child gets `$config->getData()` (its `data` option).
`mapFormsToData`: parent data null -> return (nothing written). Object -> `ConstructorMapper::mapFormsToObject()` first (readonly promoted props: rebuild via constructor, return remaining forms). Child written only if `getMapped()` && `isSubmitted()` && `isSynchronized()` && `!isDisabled()` && `isWritable()`.
Accessors: `CallbackAccessor` uses `getter`/`setter` options: `($getter)($data, $form)`, `($setter)($data, $form->getData(), $form)`. `PropertyPathAccessor::setValue` only-write-if-changed: DateTimeInterface `==` current -> skip; object && by_reference && `$value === current` -> skip; arrays always written. Reads return null for missing index (`NoSuchIndexException`) and `UninitializedPropertyException`.
Default property paths (`Form::getPropertyPath`): explicit `property_path` wins; else walking up past inherit_data parents: parent without `data_class` -> `[name]`, else `name`.
inherit_data: no own data, getters forward to parent, submit skips mapping, `InheritDataAwareIterator` makes parent's mapper descend into its children.
Other mappers: `CheckboxListMapper` (array of choice values <-> bools), `RadioListMapper` (one string <-> bools; placeholder radio -> null).

## 3. PropertyAccess
`PropertyPath`: `foo.bar` property, `foo[bar]` index, trailing `?` null-safe, `\.` escapes dot. API: `getLength`, `getParent`, `getElements`, `getElement($i)`, `isProperty($i)`, `isIndex($i)`, `isNullSafe($i)`, `__toString`.
`PropertyAccessor`: `getValue`, `setValue(&$objectOrArray, ...)`, `isReadable`, `isWritable`; flags `MAGIC_GET|MAGIC_SET|MAGIC_CALL`, `THROW_ON_INVALID_INDEX|THROW_ON_INVALID_PROPERTY_PATH`; optional `[*]` wildcard reads. Reading via PropertyInfo `ReflectionExtractor`: get/is/has/can getter or public property. Writing: reads path up to last element by reference, writes last element, writes back up the chain until an object (makes nested arrays work). `writeIndex` `$arr[$k]=$v`; `writeProperty` setter / public property / adder-remover pair for iterables (`writeCollection`: singularize name -> `addTag`/`removeTag`; `remove*` for old items not `in_array(..., true)`, `add*` for new). `isReadable`/`isWritable` = try traversal, catch `AccessException`.
Minimal subset: parser for `a.b[c]`; read index/getter get|is|has/public prop; write index/`setX`/public prop/adder-remover for iterables (collections with by_reference=false); nested array write-back by reference. Drop caching, wildcards, magic `__call`, null-safe, DateTime retry.

## 4. Transformation failures -> errors
`TransformationFailedException` carries `getInvalidMessage()` + `getInvalidMessageParameters()`. After: `getTransformationFailure()` set, `isSynchronized()` false, `modelData` null (normData null unless computed before), `viewData` = raw submitted value (re-renders input), parent mapper skips child (parent model keeps old value), `getExtraData()` filled independently before mapping.
Error creation, two paths: (a) fallback `TransformationFailureListener` (added by `TransformationFailureExtension` only when `constraints` option not set) at POST_SUBMIT prio -1024: nothing if form has errors or any child unsynchronized; else `FormError` with `invalid_message` + `array_replace(['{{ value }}' => viewDataAsString], invalid_message_parameters)` (ignores exception's own invalidMessage). (b) Validator path `FormValidator.php:185`: `$failure->getInvalidMessage() ?? invalid_message`, params merged `{{ value }}` then option's then exception's; code `Form::NOT_SYNCHRONIZED_ERROR`. Extra fields -> `NO_SUCH_FIELD_ERROR` unless `allow_extra_fields`. Defaults: `'invalid_message' => 'This value is not valid.'`, `'invalid_message_parameters' => []`. `MissingConstructorArgumentsException` puts errors on its `emptyForms`.
`MissingDataHandler` (request handlers): fills missing fields (absent checkbox -> `false_values[0]` null; compound -> `[]`; with `allow_delete` skips re-adding deleted entries).

## 5. Transformers (Extension/Core/DataTransformer/) and listeners
Transformers: `BooleanToStringTransformer` (CheckboxType view; `false_values`); `ChoiceToValueTransformer` / `ChoicesToValuesTransformer` (ChoiceType); `NumberToLocalizedStringTransformer`, `IntegerToLocalizedStringTransformer`, `MoneyToLocalizedStringTransformer`, `PercentToLocalizedStringTransformer`, `StringToFloatTransformer` (number family); `BaseDateTimeTransformer`, `DateTimeToStringTransformer`, `DateTimeToLocalizedStringTransformer`, `DateTimeToArrayTransformer`, `DateTimeToTimestampTransformer`, `DateTimeToHtml5LocalDateTimeTransformer`, `DateTimeToRfc3339Transformer` (unused), `DateTimeImmutableToDateTimeTransformer`, `DatePointToDateTimeTransformer`, `ArrayToPartsTransformer`, `DataTransformerChain`, `DateIntervalToArrayTransformer`, `DateIntervalToStringTransformer`, `WeekToArrayTransformer`, `DateTimeZoneToStringTransformer`, `IntlTimeZoneToStringTransformer`, `UuidToStringTransformer`, `UlidToStringTransformer`, `ValueToDuplicatesTransformer` (RepeatedType). Root: `CallbackTransformer`, `ReversedTransformer`. TextType is its own view transformer when `empty_data === ''`.
Listeners (Extension/Core/EventListener/): `TrimListener` (PRE_SUBMIT, `StringUtil::trim`; FormType trim=true); `FixUrlProtocolListener` (SUBMIT; UrlType); `ResizeFormListener` (see types survey §4); `MergeCollectionListener` (SUBMIT; merges new array into original norm collection matching `===`; ChoiceType multiple && by_reference); `TransformationFailureListener` (§4).

## 6. Reduced implementation
Indispensable: TransformationFailureListener logic (or inside validator); TrimListener; BooleanToStringTransformer + false_values/missing-data rule; ChoiceToValue(s)Transformer; simple non-intl Number transformer incl. integers; DateTimeToStringTransformer + ReversedTransformer; ResizeFormListener; optionally CallbackTransformer and MergeCollectionListener. Keep DataMapper with two accessors; CheckboxListMapper/RadioListMapper if expanded choices.
Droppable: all intl/localized, Money, Percent, Html5, Rfc3339, Array/Parts, Chain, Interval, Week, Timezone, Uuid/Ulid, Immutable/DatePoint, Duplicates, FixUrlProtocolListener, ConstructorMapper.
