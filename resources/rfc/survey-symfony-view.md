# Survey: Symfony Form — FormView, renderer, validation bridge, CSRF, request handling
(Read-only survey by a research agent, 2026-10-15. Notes: `Resources/` holds only translations; theme templates and `form_row` etc. live in symfony/twig-bridge, not in scope — items marked [bridge] are from memory. The class is `FormTypeValidatorExtension`, not ValidatorTypeExtension. CSRF validates at PRE_SUBMIT, validator at POST_SUBMIT.)

## 1. FormView
Holds `public array $vars` (defaults `value=>null`, `attr=>[]`), `public array $children`, `public ?self $parent`, private `rendered`, `methodRendered`; ArrayAccess/Iterator/Countable over children. `isRendered()` true if marked or if every child rendered (cached).
Tree built in `Form::createView`: `$type->createView($form, $parent)`, `buildView` (parent type, inner type, extensions), child `createView($view)` for each child, sort by `priority`, `finishView` (same order; sees finished children; `multipart` bubbles up; `form_id` resolved). Views are snapshots (`errors`, `value`, `valid` read at build time) -> create view after submit.
Vars from `BaseType::buildView` (every view incl. buttons): `form`, `id`, `form_id`, `name`, `full_name`, `disabled`, `label`, `label_format`, `label_html`, `multipart`, `attr`, `block_prefixes`, `unique_block_prefix`, `row_attr`, `translation_domain`, `label_translation_parameters`, `attr_translation_parameters`, `priority`, `cache_key`. Child `id` = `parent.id + '_' + name`; `full_name` = `parent[name]`; `unique_block_prefix` = `parent.unique_block_prefix + '_' + block_name`. Root `id` = name (or string `form_attr`, leading `_`/digits stripped); `unique_block_prefix` = `'_' + name`. `cache_key` = `unique_block_prefix + '_' + typeBlockPrefix`. Label/attr/translation params merge from parent; parent `readonly` attr propagates down.
Vars from `FormType::buildView` (not buttons): `errors` (`$form->getErrors()`), `valid`, `value` (view data), `data` (norm data), `required`, `label_attr`, `help`, `help_attr`, `help_html`, `help_translation_parameters`, `compound`, `method`, `action`, `submitted`.
Type-specific: Checkbox `checked`, `value`; File `type`, `value=''`, `multipart=true`, `full_name.='[]'` when multiple; Choice `choices`, `preferred_choices`, `placeholder`, `placeholder_in_choices`, `is_selected`, `[]` when multiple; Submit `clicked`; Collection `prototype`, `allow_add`, inserts `collection_entry` into entries' `block_prefixes`.
`block_prefixes`: walk type chain root->leaf (`getBlockPrefix()`, default FQCN snake-case minus "Type"), append `block_prefix` option if set, then `unique_block_prefix`. Example EmailType child `email` of form `myform`: `['form','text','email','_myform_email']`. Lookup from last entry backwards: `_myform_email_widget` -> `email_widget` -> `text_widget` -> `form_widget`.

## 2. FormRenderer and engines
`FormRendererInterface`: `setTheme(view, themes, useDefaultThemes)`, `renderBlock(view, blockName, vars)`, `searchAndRenderBlock(view, suffix, vars)`, `renderCsrfToken(tokenId)`, `humanize(text)`. `FormRendererEngineInterface`: `setTheme`, `getResourceForBlockName`, `getResourceForBlockNameHierarchy`, `getResourceHierarchyLevel`, `renderBlock(view, resource, blockName, vars)`.
`AbstractRendererEngine`: themes per `cache_key`; only abstract method `loadResourceForBlockName($cacheKey, $view, $blockName): bool`; `loadResourceForBlockNameHierarchy` tries current level then recurses to level-1, caches parent's resource under child block name, caches misses. [bridge] Twig engine searches view's own themes, then parent views' themes up the tree, then defaults.
`searchAndRenderBlock`: builds `prefix_suffix` names, resolves deepest existing level; keeps `blockNameHierarchyMap` and `hierarchyLevelMap` keyed `cache_key + suffix` (a block calling the same helper again on same view resumes one level up = parent-type fallback); vars = `view->vars` `array_replace` passed vars, `attr`/`label_attr` merged key by key, pushed on `variableStack[cache_key]`; throws `LogicException` if no block.
Rendered state: only `row` and `widget` suffixes are render-once (second call -> `BadMethodCallException`; success -> `setRendered()`). `isMethodRendered`/`setMethodRendered` track hidden `_method`.
[bridge] Helpers: `form_widget/label/errors/help/row/rest` = `searchAndRenderBlock` with that suffix; `form_start`/`form_end`/`form` = `renderBlock`. `form_row` = label + widget + help + errors in a div with `row_attr`. Compound `form_widget` renders children's rows then `form_rest`. `form_rest` renders row of every child with `isRendered()` false. `form_end` calls `form_rest` unless `render_rest` false, then `</form>`. `form_label` uses `humanize(name)` when label null; `label=false` suppresses.

## 3. Validation
Setup: `ValidatorExtension` adds `new Form()` and `new Traverse(false)` to Form class metadata; registers `FormTypeValidatorExtension` (options `constraints`, `error_mapping`, `allow_extra_fields`, `extra_fields_message`, `invalid_message`, `invalid_message_parameters`; `validation_groups` from `BaseValidatorExtension`) plus Bounds/Repeated/Submit extensions.
When: `ValidationListener` attached in `buildForm`, listens POST_SUBMIT, acts only when `$form->isRoot()`: `validator->validate($form)`, `mapViolation` each (passing `allowNonSynchronized` for `Form::NOT_SYNCHRONIZED_ERROR`), then POST_VALIDATE deepest children first.
`FormValidator`, submitted & synchronized: resolve groups (empty -> stop); at root only (or current flow step), if data object/array: `atPath('data')->validate($data, null, $groups)` (nested objects need `Valid`); `constraints` option validated at `data`, each constraint only in first matching group (`Composite` excepted), `Valid` in all groups; recurse `atPath('children[name]')` with `Form` constraint per submitted child, remembering groups in `resolvedGroups`; with `GroupSequence` run per group, stop at first group adding violations.
Not synchronized: recurse into unsynchronized children; add `invalid_message` (code `NOT_SYNCHRONIZED_ERROR`, `{{ value }}`) only if all children synchronized. Always: unless `allow_extra_fields`, non-empty `getExtraData()` -> `extra_fields_message` code `NO_SUCH_FIELD_ERROR`.
Groups: clicked button's `validation_groups` wins; else walk up parents for first non-null `validation_groups` or remembered group; else `['Default']`; option normalizes false -> `[]` (skip); callable receives form.
`ViolationMapper`: `ViolationPath` parses `children[a].children[b].data.c.d` (`children[x]` -> `mapsForm=true`; after `data` property elements). `reconstructPath` replaces each `children[x]` with child's property path, drops inherit_data children's segments -> `RelativePath` rooted at form. Descent from root while `acceptsErrors` (synchronized or allowNonSynchronized): `matchChild` grows path chunk element by element; first tests `error_mapping` rules (`MappingRule`: exact match returns target; `isPrefix` keeps rule alive; targets dot-separated child names); then compares candidate children (flattened through inherit_data by `InheritDataAwareIterator`) whose `getPropertyPath()` string equals chunk; longest match wins; camelized retry. Property paths `[name]` when parent has no `data_class`, `name` otherwise; unmapped children still have name-based paths, their own `constraints` errors arrive via `children[x].data`. Fallback: walk `mapsForm` segments to innermost existing child. `error_mapping['.']` redirects repeatedly. `{{ label }}` substituted from `label_format`/`label`/humanized name. Result `addError(new FormError(...))`; `Form::addError` forwards to parent while `error_bubbling` (default `compound && !inherit_data`: leaves keep errors, compound subforms bubble).

## 4. CSRF (Extension/Csrf/)
`CsrfExtension` registers `FormTypeCsrfExtension` (extends FormType). Options `csrf_protection` (true), `csrf_field_name` (`_token`), `csrf_message`, `csrf_token_manager`, `csrf_token_id`. Token id: `csrf_token_id`, else `defaultTokenId[innerTypeFQCN]`, else form name, else inner type FQCN; stored as builder attribute `csrf_token_id`. Field is NOT a real child: in `finishView`, root compound only, a `HiddenType` form (`block_prefix 'csrf_token'`, `mapped=false`) is created and its view added as `view->children[_token]`. Validation: `CsrfValidationListener::preSubmit` (PRE_SUBMIT), root compound only, skipped if post_max_size exceeded; `isTokenValid(new CsrfToken(id, data[field]))`, failure -> `FormError` with token as cause; always `unset`s field from submitted data (never extra data). `submit()` clears errors before PRE_SUBMIT.

## 5. Request handling
`Form::handleRequest($req)` -> `config->getRequestHandler()->handleRequest($this, $req)`. Default shared `NativeRequestHandler` (FormConfigBuilder); `FormTypeHttpFoundationExtension::buildForm` sets `HttpFoundationRequestHandler` (same logic on `Request->query/request/files`).
`NativeRequestHandler`: (1) `$request` must be null. (2) form `method` must equal `REQUEST_METHOD` (`X-HTTP-Method-Override` honored on POST) else return. (3) GET/HEAD/TRACE: unnamed form takes `$_GET`; named takes `$_GET[name]`, returns if missing; data through `MissingDataHandler::handle`. (4) Other methods: if `hasPostMaxSizeBeenExceeded()`: `submit(null,false)`, add `upload_max_size_message` `{{ max }}`, return; normalize `$_FILES` (`fixPhpFilesArray` per-attribute arrays -> per-file trees; `stripEmptyFiles` `UPLOAD_ERR_NO_FILE` -> null); unnamed: `$_POST` + all files; named: present if `name` in `$_POST` or files, missing sides default `[]` for compound / null otherwise, absent entirely -> return; non-PATCH: `MissingDataHandler` fills absent fields (checkbox `false_values`; compound `[]`; respects `allow_delete`); merge `FormUtil::mergeParamsAndFiles` if both arrays else `params ?: files`. (5) unnamed form submitted only if data contains at least one known child key. (6) strip `_method` when equals method and not a real field. (7) `$form->submit($data, 'PATCH' !== $method)`.
`isFileUpload` = array with integer `error`; `getUploadFileError` returns non-OK codes.

## 6. Minimal reimplementation
View vars: `id`, `name`, `full_name`, `value`, `attr`, `label` (null = humanize, false = none), `label_attr`, `errors`, `required`, `disabled`, `compound`, `block_prefixes`, `unique_block_prefix`, `cache_key`; root also `method`, `action`, `multipart`. Optional `row_attr`, `help`, `valid`, `checked`/`choices`/`multiple`/`expanded`.
Keep: FormView `rendered` with `isRendered()` checking all children; per-suffix hierarchy level map (widget block can call parent-type block); per-view variable stack.
Theme blocks: `form_start`, `form_end`, `form_rest`, `form_row`, `form_label`, `form_errors`, `form_widget` (dispatches to `form_widget_compound` looping child rows, or `form_widget_simple` `<input type=...>`), `hidden_row`/`hidden_widget`, `textarea_widget`, `checkbox_widget`, `choice_widget`, `button_widget`/`submit_widget`; optional `csrf_token`, `form_help`. Twig blocks map naturally to Volt partials/macros looked up by name through `block_prefixes`.
Guessers: `FormTypeGuesserInterface` (`guessType`, `guessRequired`, `guessMaxLength`, `guessPattern`) -> `Guess\TypeGuess(type, options, confidence)` / `ValueGuess`; confidence LOW..VERY_HIGH (0-3); `Guess::getBestGuess`.
